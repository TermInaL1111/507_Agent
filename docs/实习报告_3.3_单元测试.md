# 3.3 单元测试

## 3.3.1 测试策略

本项目的单元测试遵循 TDD（测试驱动开发）原则，采用 **pytest** 框架。测试目标：覆盖核心业务逻辑（schedule_service、document_generator），验证正常路径、边界条件和错误处理。

**测试环境**：Docker 容器内 `python3 -m pytest tests/ -v`
